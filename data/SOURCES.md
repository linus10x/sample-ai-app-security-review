# Data sources

Everything in this repository is synthetic. No real customer, employer or personal data is used.

| Data | Origin | License |
|---|---|---|
| 3 organisations, 12 users, 40 products, 9 paid orders with invoices and shipments | Generated by `scripts/seed.ts`. Names, emails (all at example.com) and products are made up. The script is deterministic and safe to run twice. | Generated, released with the code under MIT OR Apache-2.0 |
| Demo password `demo-password-1` | Chosen for the demo accounts only. It protects nothing. | Not applicable |
| Card numbers | None. Stripe runs against stripe-mock, which answers with canned responses. No card number is typed or stored anywhere. | Not applicable |
| Supabase local keys | Created by the Supabase CLI for your own machine each time it starts. They are never committed. `.env.example` holds fake placeholders. | Not applicable |

Third-party software is used under its own license: Next.js, React, Supabase, Stripe's Node library and stripe-mock, Vitest, Playwright, Semgrep, gitleaks, osv-scanner and OWASP ZAP.
